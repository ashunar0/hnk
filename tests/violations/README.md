# 違反サンプル

**規則が鳴ることを確かめるためだけのコード。** 動かないし、型も通らない。

検査が沈黙するのは、違反が無いときと、検査自体が壊れているときの区別がつかない。
実際 `oxlint .` は gitignore を尊重して features/ を丸ごと飛ばしながら緑を返していた。
ここは各規則に対して「これを見せたら必ず鳴る」1 件を持つ。

`fixture/` の外に置く理由は、fixture 内だと `oxlint .` が拾ってしまうことと、
`package.json` の `files` に `fixture/api` が入っていて npm で配られてしまうこと。
